API Reference
=============

The MiniNumPy API provides a lightweight, NumPy-like interface for working with
multidimensional arrays and performing fundamental linear algebra operations.

This section documents all public functions that can be accessed via:

.. code-block:: python

    import MiniNumPy as mnp

    a = mnp.array(...)
    mnp.linalg.matmul(...)
